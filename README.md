# 🔥 PianoMaR — Virtual Piano

A beautiful virtual piano web app with **real piano samples**, playable using your PC keyboard.

**[Live Demo →](https://pianomar.vercel.app)**

![PianoMaR Screenshot](https://img.shields.io/badge/🎹-Virtual_Piano-ff3b1a?style=for-the-badge)

## ✨ Features

- 🎹 **5 Octaves** (C2–C7) — 61 keys (36 white + 25 black)
- 🎵 **Real Piano Samples** — Soundfont-based audio from MusyngKite
- ⌨️ **Full Keyboard Mapping** — `1234567890`, `qwertyuiop`, `asdfghjkl`, `zxcvbnm`
- 🎼 **Shift = Sharp/Black Keys** — Hold Shift + key for sharps
- 🔄 **Transpose** — ±12 semitones
- 🦶 **Sustain Pedal** — Space key
- 🎛️ **15 Instruments** — Grand Piano, Electric Piano, Organ, Music Box, and more
- 🔥 **Fire Red Theme** — Animated ember particles and glow effects
- 📱 **Responsive** — Works on desktop, tablet, and mobile

## 🎮 How to Play

| Action | Key |
|--------|-----|
| White keys | `1-0`, `Q-P`, `A-L`, `Z-M` |
| Black keys (sharps) | `Shift` + same key |
| Sustain pedal | `Space` |

## 🛠️ Tech Stack

- **HTML/CSS/JS** — Vanilla, no framework
- **Web Audio API** — For audio playback
- **soundfont-player** — Real instrument samples from CDN
- **Vercel** — Hosting
